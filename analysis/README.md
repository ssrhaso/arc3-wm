# analysis/

Evidence artifacts backing the paper's result tables. The committed data
files are the durable record; the builders that read local-only run
artifacts are kept for provenance and are not runnable from a fresh clone.

## Paired sweep and diagnosis
- `p4_fromscratch_vs_proper.md` - paired cold-versus-warm RHAE comparison at 500k env-steps.
- `p4_cross_cell_diagnosis.md` - the dissociation between world-model fit and controller failure across the 6 pilot warm cells.
- `build_p4_combined.py`, `build_p4_cross_cell_diagnosis.py` - regenerate the two documents above from local run logs.
- `run_tree_aggregate_2026-09-06.csv` - one row per run of the full run tree; the input to `scripts/build_iclr_tables.py`.

## Frozen-model probes
- `probe_refit.{csv,json,md}` - the latent probes re-scored with permutation tests and Holm correction, written by `scripts/probe_refit.py`.

## lf52 episode lengths
- `lf52_episode_lengths.csv` - one row per episode behind the `lf52` episode-length analysis, written by `lf52_episode_lengths.py`.

`benchmark_table.{md,json}` are generated by `scripts/build_benchmark_table.py` and are gitignored.
